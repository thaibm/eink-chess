# Post-Game Analysis — EinkChess

> Canonical HTML: <https://einkchess.fun/analysis.html>

Review a finished game move by move. The analysis view shows an evaluation
advantage readout for each position and flags tactical mistakes, all computed
locally in the browser.

Analysis runs on the most recent game stored in your browser, so play a game
first at </md/play-bot-v2.md>. Analysis depth is configurable before the run
starts.
